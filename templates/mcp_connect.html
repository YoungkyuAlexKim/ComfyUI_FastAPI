연결 확인

아래 문장은 이미지를 생성하지 않아 외부 이미지 API 비용이 들지 않습니다.

LC AI Canvas에서 사용할 수 있는 이미지 생성 기능과 옵션을 알려줘. 아직 이미지는 생성하지 마.

기능 목록이 나오면 연결된 상태입니다.

사용 방법

“게임 UI용 보석 버튼을 만들어줘”처럼 요청할 수 있습니다. 모델·크기·비율이 빠졌거나 비용이 생기는 작업은 실행 전에 필요한 내용을 확인합니다.

비용

외부 이미지 생성·편집 API는 실제 비용이 발생합니다. 기능 조회와 자산 목록 조회는 무료이며, 로컬 배경 제거(RMBG)는 외부 API 비용이 없습니다.

결과 확인

MCP로 만든 이미지가 보이지 않으면 MCP 설정과 같은 사내 주소로 갤러리를 열고 표시되는 “연결하기”를 한 번 눌러 주세요.
