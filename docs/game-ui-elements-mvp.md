# 게임 UI 엘리먼트 메이커 MVP

## 제품 범위

- 지원 에셋: 사용자가 자연어로 설명할 수 있는 독립형 게임 UI 엘리먼트
- 입력: 텍스트 필수, 스타일 레퍼런스 이미지 최대 3장 선택
- 생성: GPT Image 2 전용, 2K·Medium 기본값
- 출력: 같은 요청에 대한 대안 4개를 2×2 시트 한 장으로 생성
- 후처리: 시트를 4셀로 분리하고 크로마 매트를 알파로 변환
- 파생본: 자연스러운 가로세로 비율을 유지한 채 긴 변 기준 32·64·128·256 단계 모두 보관
- 관리: 갤러리에서 4개를 한 묶음으로 표시하고 ZIP으로 다운로드

아이콘·버튼·프레임·배지 같은 의미 분류는 별도 모드로 강제하지 않는다. 예를 들어 원형 버튼이나 배지 형태의 아이콘도 그대로 자연어로 요청할 수 있다. `64` 파생본은 엘리먼트의 긴 변이 64픽셀이 되며 짧은 변은 원래 비율에 맞춰 결정된다.

## 사용자 흐름

1. 예시 프롬프트에서 시작하거나 원하는 소재·용도·형태·스타일을 직접 설명한다.
2. 필요한 경우 스크린샷이나 영감 이미지를 최대 3장 추가한다.
3. 투명 PNG 자동 분리 여부를 선택한다.
4. `후보 4개 만들기`를 실행한다.
5. 결과 그룹에서 셀을 고르고 크기별 PNG 또는 전체 ZIP을 받는다.

## 의도적으로 제외한 항목

- 전체 HUD나 완성 UI 화면 생성
- 3×3·4×4 시트와 서로 다른 아이템 세트
- 버튼 hover/pressed/disabled 상태 세트
- 패널, 9-slice, 엔진별 임포트 패키지
- 선택 셀의 고품질 재생성과 유사 변형

## 현재 제약

- 2×2 분리는 모델이 중앙선을 넘지 않았다는 전제의 고정 분할이다.
- 크로마키와 거의 같은 전경색은 알파 처리에 영향을 받을 수 있다.
- 모델이 그림자나 광원을 크로마 배경에 흘리면 가장자리에 색 번짐이 남을 수 있다.
- 묶음 삭제는 아직 개별 이미지의 기존 삭제 동작을 사용한다.

다음 제품 검증에서는 실제 게임 프로젝트의 아이콘·버튼·프레임 샘플로 `셀 침범률`, `알파 가장자리`, `소형 가독성`, `4안 다양성`을 우선 측정한다.
